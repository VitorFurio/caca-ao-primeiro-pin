Capítulo 01

A caça tem trilha sonora

Nenhum arquivo de áudio: todos os sons abaixo são sintetizados na hora pelo Web Audio — papel, carimbo, moedas, o rangido do baú. Zero download, funciona offline. Toque num botão (o navegador exige um primeiro toque para liberar o som) e ligue a atmosfera da caverna para ouvir o vento contínuo.

Técnica: Web Audio API — osciladores + ruído filtrado com envelopes · sempre com botão de mudo visível (canto da tela)
Capítulo 02

O dedo é o novo mouse — e é melhor

No celular não existe hover: tudo precisa responder ao toque direto. Dois padrões fortes: o toque que deixa marca (com som e vibração juntos — tríade sensorial), e o segurar para selar — pressionar e manter por um segundo, como quem pressiona um carimbo de verdade contra o papel. Muito mais cerimonial que um clique.

Toque em qualquer lugar cada toque deixa cera + som + vibração
as marcas ficam na página
Segure para selar
pressione e segure o círculo
Técnica: Pointer Events · anel de progresso SVG (stroke-dashoffset) · vibração em marcos do progresso · -webkit-touch-callout:none para não abrir menu do sistema
Capítulo 03

Gestos que o polegar já conhece

Deslizar e beliscar são linguagem nativa do celular. As tarefas da caça podem virar um baralho de cartas — desliza para o lado para folhear —, e o mapa pode ganhar zoom de pinça para examinar de perto, como quem aproxima uma lupa do pergaminho.

Deslize a carta para o lado
Belisque para dar zoom · arraste para mover
no desktop: arraste com o mouse
Técnica: Pointer Events com dois dedos (escala pela distância entre toques) · touch-action:pan-y no baralho preserva a rolagem vertical da página
Capítulo 04

Incline o aparelho, mova a luz

O efeito mais mágico do celular: a lanterna do mapa deixa de seguir um mouse que não existe e passa a seguir a inclinação física do aparelho — o celular vira a própria lanterna. O cartão 3D também inclina com o corpo. No iPhone o navegador pede permissão, por isso o botão abaixo.

Capítulo 05

Chacoalhe para abrir o baú

O acelerômetro detecta uma chacoalhada — e esse pode ser o ritual de abertura do tesouro final: "complete as 6 tarefas e chacoalhe o celular para abrir o baú". Impossível de esquecer. Ative os sensores no capítulo anterior e chacoalhe; no desktop, use o botão.

Capítulo 06

Padrões de vibração são vocabulário

Uma vibração não é só "buzz": padrões diferentes comunicam coisas diferentes — um tique leve confirma, um golpe seco carimba, uma sequência crescente celebra. Importante: o iPhone não expõe vibração para páginas web; no Android funciona. Por isso ela é sempre reforço, nunca o único aviso.

Técnica: navigator.vibrate([padrão]) · Android ✓ · iPhone ✕ (usar som + animação como reforço)
