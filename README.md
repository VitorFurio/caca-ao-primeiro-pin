# Caça ao Primeiro Pin

Experiência digital da trilha do novo associado — Rotaract Club de Jaraguá do Sul.

- **`app.html`** — o app principal: introdução ao clube, as 4 missões e o gerador da Carta de Intenção.
- **`laboratorio-de-efeitos.html`** — laboratório de efeitos visuais (desktop).
- **`laboratorio-mobile.html`** — laboratório de recursos de celular (toque, som, giroscópio, vibração).
- **`laboratorio-bibliotecas.html`** — laboratório de bibliotecas (GSAP, Matter.js, canvas-confetti, Three.js).
- **`index.html`** — primeira versão do mapa (mantida como referência).
